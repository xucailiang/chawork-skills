本 skill 用于指导创建独具特色、达到生产级品质的前端界面，避免落入千篇一律的"AI 味"审美。它会用真正可运行的代码来实现需求，并在审美细节与创意选择上倾注极致用心。

用户会提供前端需求：一个组件、一个页面、一个应用，或一段界面。需求中可能包含关于用途、受众或技术约束的上下文。

## 设计思考

动手写代码之前，先理解上下文，并在审美方向上做出**大胆**的取舍：
- **目的**：这个界面要解决什么问题？谁来使用？
- **基调**：挑一个极致方向：极简到野蛮、极繁主义混沌、复古未来主义、有机/自然、奢华/精致、俏皮/玩具感、编辑/杂志风、粗野/原生、装饰艺术/几何、柔和/粉彩、工业/实用主义等等。可选的风味数不胜数。把这些当作灵感来源，然后设计一个真正忠于所选审美方向的版本。
- **约束**：技术要求（框架、性能、无障碍）。
- **辨识度**：是什么让它**令人难以忘怀**？人们记住的那一件事是什么？

**关键**：选定一个清晰的概念方向，然后以精确度去执行。大胆的极繁主义和精致的极简主义都行得通——关键在于刻意而非强度。

然后写出可运行的代码（HTML/CSS/JS、React、Vue 等），做到：
- 达到生产级、功能完整
- 视觉上震撼、令人难忘
- 拥有清晰审美主张、整体协调一致
- 在每一个细节上都打磨到极致

## 前端审美指南

聚焦于：
- **字体**：选择美观、独特、有趣味的字体。避开 Arial、Inter 这类通用字体；转而选择能提升整体审美的、有辨识度的、出人意料且有个性的字体。把一款有性格的展示字体与一款精致的正文字体搭配在一起。
- **色彩与主题**：坚守一套协调统一的审美。使用 CSS variables 保持一致性。带有锋利点缀色的主色调，远胜于怯生生、均匀铺陈的调色板。
- **动效**：把动画用在效果和微交互上。在 HTML 中优先采用纯 CSS 方案。React 项目在可用时使用 Motion 库。把火力集中在最具张力的瞬间：一次精心编排、配合 animation-delay 错落展开的页面入场，比一堆散乱的微交互更能制造惊喜。运用能带来意外感的滚动触发与悬停态。
- **空间构图**：出乎意料的版面。非对称。重叠。对角线动线。打破网格的元素。慷慨的留白，或受控的密集感。
- **背景与视觉细节**：营造氛围与纵深感，而不是默认上一片纯色。叠加与整体审美匹配的情境化效果和纹理。运用一些有创意的形式，比如渐变网格、噪点纹理、几何图案、分层透明、戏剧性阴影、装饰性边框、自定义光标和颗粒覆盖层。

**绝不**使用通用的 AI 生成审美：被用烂的字体（Inter、Roboto、Arial、系统字体）、陈词滥调的配色（尤其是白底紫色渐变）、可预测的布局与组件套路，以及那种缺乏特定语境个性的模板化设计。

请发挥创造性地理解需求，做出真正贴合上下文的出人意料的选择。没有任何两份设计应该是一样的。在明亮与黑暗主题之间切换、在不同字体之间切换、在不同审美之间切换。**绝不**让多次生成都收敛到同一些大众选择（例如 Space Grotesk）。

**重要**：让实现复杂度与审美愿景相匹配。极繁主义的设计需要繁复的代码、密集的动画和效果。极简或精致的设计则需要克制、精确，以及对间距、字体和微妙细节的悉心打磨。优雅源于把所选愿景执行到位。
